# ClipEdit（配布版）

コピーした文字を、ショートカットキーひとつで開いて直せる Windows 用の小さなツールです。
直して Ctrl+Enter を押すとクリップボードが書き換わるので、あとは貼りたい場所で Ctrl+V を押すだけです。

- インストール不要。`clipedit.exe` 1つで動きます（ランタイムなどの追加も不要）
- ネットワークには一切つながりません。ログも残しません

## 動作環境

- Windows 10（バージョン 1703 以降）/ Windows 11、64bit

## はじめに

1. `clipedit.exe` を、自分だけが使うフォルダに置きます（例：`C:\Users\<ユーザー名>\Apps\ClipEdit\`）
2. `clipedit.exe` をダブルクリックして起動します
3. 画面右下のタスクトレイに、青いクリップボードのアイコンが出れば準備完了です

置き場所について：

- 「ダウンロード」フォルダや、ほかの人も書き込めるフォルダに置いたまま使うのは避けてください
  - 「ダウンロード」フォルダは、Windows の「ストレージ センサー」の設定によって、しばらく開いていないファイルが自動で削除されることがあり、`clipedit.exe` やお気に入り（`favorites` フォルダ）が消えてしまうおそれがあります
  - ブラウザなどがファイルを置く場所なので、ログインのたびに自動で動くプログラムを置くには向きません
- `C:\Program Files` にも置かないでください。ここは、ふつうに起動したアプリからは書き込めない場所です（右クリックの「管理者として実行」で起動したときだけ書けます）。お気に入りは `clipedit.exe` と同じフォルダに保存するので、「お気に入りに追加」が失敗します
- Windows 11 では、アイコンは最初「^」の中に隠れています。タスクバーへドラッグすると、いつも見えるようになります

### 「WindowsによってPCが保護されました」と出たら

この exe にはデジタル署名がなく、ダウンロードの実績も少ないため、ダウンロードして最初に起動したときに、この画面が出ることがあります。
入手元が信頼できる場合は、「詳細情報」→「実行」で起動できます。

「実行」が出ない、または何も表示されずに起動できないときは、Windows 11 なら「設定」→「プライバシーとセキュリティ」→「Windows セキュリティ」→「アプリとブラウザーコントロール」を開いてください。「スマート アプリ コントロール」が「オン」だと、署名のない ClipEdit は起動を止められることがあります。会社や学校の PC では、管理者の設定で止められていることもあります。

ClipEdit は GitHub の Releases ページ（https://github.com/naktomo-svg/ClipEdit/releases ）で公開しています。ここから入手した場合は、そのページに書いてある手順（`SHA256SUMS.txt` との照合など）で、ファイルが書き換えられていないことを確かめられます。

## 使い方

1. 直したい文字をコピーする
2. **Ctrl+Alt+V** を押す（マウスのある画面の中央に、編集ウィンドウが開きます）
3. 直して **Ctrl+Enter** を押す（クリップボードが書き換わり、ウィンドウが閉じます）
4. 貼りたい場所で **Ctrl+V** を押す

キーの一覧：

- Ctrl+Alt+V：編集ウィンドウを開く
- Ctrl+Enter：クリップボードに書き込んで閉じる
- Esc / × ボタン：書き込まずに閉じる
- Ctrl+A：すべて選択
- Ctrl+Backspace：直前の1語を消す（日本語は、ひらがな・カタカナ・漢字の切り替わりで区切ります）
- Ctrl+Z：元に戻す
- Ctrl+1〜Ctrl+9：お気に入りの 1〜9 番目に入れ替える。直前の1回だけ Ctrl+Z で戻せます（「残さない」印つきの内容から入れ替えたときや、長い行のお気に入りのときは戻せません）。AltGr（Ctrl+Alt）+ 数字は、お気に入りの呼び出しとして扱いません
- Alt+F：メニューバーの「お気に入り」を開く

- 開いている間にもう一度 Ctrl+Alt+V を押しても、編集中の内容は消えません
- クリップボードが画像などテキスト以外のときは、空の状態で開きます（タイトルに「(テキストなし)」と出ます）
- 閉じると、編集欄の内容は消えます。次に開くときは、そのときのクリップボードを読み直します
- 改行のないとても長い行（5,000 文字を超えるもの）があるときは、折り返さずに横スクロールで表示します（タイトルに「(長い行があるため折り返さずに表示)」と出ます。折り返すと、開くのにとても時間がかかるためです）
- クリップボードに書き込めなかったとき（ほかのアプリが使っているときなど）は、ウィンドウを閉じずに、タイトルに「書き込み失敗」と理由が出ます。編集欄の中のコピー・切り取りも同じで、「コピー失敗」「切り取り失敗」と出ます（切り取ったところは消えません。次に成功すると元に戻ります）。もう一度試してください

### タスクトレイのメニュー

アイコンを左クリックすると、編集ウィンドウが開きます。右クリックすると、次のメニューが出ます。

- **開く**：編集ウィンドウを開く
- **お気に入り**：お気に入りの一覧。選ぶと、そのお気に入りを入れた状態で編集ウィンドウが開きます。最後の「お気に入りを整理…」でフォルダが開きます
- **ログイン時に起動**：チェックすると、Windows にサインインしたときに自動で起動します
- **設定を読み直す**：`config.toml` の変更を反映します（書き方が違う・新しいキーがほかのアプリに使われているときは、それまでのキーのまま使えます）
- **終了**：ClipEdit を終了します

exe を別の場所へ移したときは、チェックが外れた「ログイン時に起動（別の場所の exe が登録されています）」の表示になります。もう一度選ぶと、新しい場所で登録し直します。

## お気に入り（よく使うプロンプトを呼び出す）

よく使うプロンプトを保存しておき、編集ウィンドウにすぐ呼び出せます。呼び出すと、編集欄の中身がまるごとそのお気に入りに入れ替わります。直した内容はその回だけのもので、保存してあるお気に入りは変わりません。

- 保存場所：`clipedit.exe` と同じフォルダの `favorites` フォルダ。1つのお気に入りが1つの `.txt` ファイルです。暗号化はしません。ふつうのテキストファイルです。`clipedit.exe` は、自分で書き込めるフォルダに置いてください（`C:\Program Files` では保存できません。下の「よくある質問」を参照）
- 見本：zip の `favorites` フォルダに、すぐ試せるプロンプトが8本入っています（`01 要約して箇条書き.txt` など）。起動して編集ウィンドウを開き、Ctrl+1 を押すと1本目が入ります。いらないものは消し、自分のプロンプトに書き換えて使ってください
  - 新しい版に入れ替えるときは、`clipedit.exe` だけを上書きしてください。zip の `favorites` フォルダごと上書きすると、書き換えた見本が元に戻ります
- ファイル名：`<番号> <名前>.txt`（例：`01 コードレビュー依頼.txt`）。一覧には番号と `.txt` を除いた名前が出て、番号の小さい順に並びます。番号のないファイルは、番号つきのものの後ろに並びます
- 呼び出す番号は、一覧での位置（上から 1, 2, 3, …）です。ファイル名の番号そのものではありません（`01` と `05` だけなら、`05` は Ctrl+2 です）
- 書き直し・名前の変更・並べ替え・削除は、メモ帳とエクスプローラーでします。メニューを出すたびにフォルダを読み直すので、直した内容は次にメニューを出したときから反映されます
- 20 本まで、1つのファイルは 64KB までです。21 本目からは一覧に出さず、メニューに「上限の 20 本を超えた N 個は出していません」と出ます。64KB を超えるものや UTF-8 でないものも一覧に出ず、メニューに「読み込めないファイルが N 個あります」と出ます。中身を読むのは 100 個までなので、読み込めないファイルがたくさんあると、その先のお気に入りは出ません。メモ帳では UTF-8 で保存してください
- サブフォルダと、`.txt` 以外のファイルは無視します

使い方：

- **Ctrl+1〜Ctrl+9**：一覧の 1〜9 番目に入れ替えます（テンキーも使えます）。その番号がなければ何もしません
- **メニューバーの「お気に入り」**（Alt+F。Alt を押して離してから F でも開きます）：一覧と次の項目が出ます。1〜9 番目は、メニューが出ている間に数字キーを押しても選べます
  - **今の内容をお気に入りに追加**：編集欄の今の内容を、新しいファイルとして保存します。名前は本文の最初の空でない行から作り（30 文字まで。ファイル名に使えない文字は `_` になります）、番号は今ある最大の番号の次になります。同じ名前があれば ` (2)` などを付け、今あるファイルは上書きしません。保存すると「お気に入りの N 番に追加しました」と通知でお知らせします
  - **お気に入りを整理…**：`favorites` フォルダをエクスプローラーで開きます（なければ作ります）
- 追加できないとき（空の内容、すでに 20 本ある、64KB を超える、書き込めない）は、理由を通知でお知らせします
- パスワード管理ソフトなどが「クリップボード履歴に残さない」印を付けてコピーした内容は、お気に入りに追加できません。そうした内容を編集欄に貼り付けたときも同じです

日本語を変換している途中（文字の下に線が出ている間）は、Ctrl+数字は効きません。Enter で確定してから押してください。メニューバーの「お気に入り」か、トレイのメニューの「お気に入り」からも呼び出せます。

## ショートカットキーを変える

同梱の `config.example.toml` の名前を `config.toml` に変え、メモ帳で開いて `hotkey` の行を書き換えるのがいちばん簡単です。
自分で作る場合は、`clipedit.exe` と同じフォルダに `config.toml` という名前のテキストファイルを作り、次のように書きます。

```toml
hotkey = "Ctrl+Shift+E"
```

- 修飾キー：`Ctrl` / `Alt` / `Shift` / `Win`（1つ以上必要。大文字小文字は区別しません）
- キー：`A`〜`Z`、`0`〜`9`、`F1`〜`F24`、`Space`、`Insert`
- 文字コードは UTF-8 で保存してください（Windows 11 のメモ帳なら、そのまま保存で UTF-8 になります）
- 変更は、トレイのメニューの「設定を読み直す」を選ぶと反映されます（起動し直しても反映されます）

ホットキーを Ctrl+1〜9 にすると、編集ウィンドウでもそのキーが届かなくなり、お気に入りの呼び出しに使えなくなります（トレイのメニューからは呼べます）。

書き方が違う・ファイルが大きすぎる（64KB 超）、といった場合は、既定の Ctrl+Alt+V で起動し、トレイから通知でお知らせします。
ほかのアプリが同じキーを使っているときは、ホットキーなしで起動して通知を出します。その間もトレイのアイコンをクリックすれば開けます。

## パスワードとプライバシー

- パスワード管理ソフトが「クリップボード履歴に残さない」印を付けてコピーした文字は、ClipEdit で書き戻すときにも同じ印を付け直します。編集欄の中でコピー・切り取りしたとき（Ctrl+C・Ctrl+X・右クリックのメニュー）も同じです。印の付いた文字を貼り付けると、書き戻すときに印を付けます。Win+V の履歴やクラウド同期には残りません
- 閉じると、編集欄の内容と「元に戻す」の履歴を消します
- 通信はしません
- PC にファイルを作るのは、「お気に入りに追加」を選んだときだけです（`favorites` フォルダの中に、暗号化しないテキストとして保存します）。ほかに、「お気に入りを整理…」を選んだときに `favorites` フォルダがなければ、空のフォルダを作ります。「残さない」印つきの内容は追加できません

## アンインストール

1. タスクトレイのメニューで「ログイン時に起動」のチェックを外す。「ログイン時に起動（別の場所の exe が登録されています）」と出ているときは、2回選ぶ（1回目で今の場所に登録し直してチェックが付き、2回目でチェックが外れて登録が消える）
2. 「終了」で ClipEdit を終了する
3. `clipedit.exe`（と、作っていれば `config.toml` と `favorites` フォルダ）を削除する

ClipEdit が PC に残すのは、「ログイン時に起動」をオンにしたときのレジストリの値（`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` の `ClipEdit`）と、`favorites` フォルダ（zip に入っていた見本と、自分で追加したお気に入り）だけです。レジストリの値は手順1でチェックを外すと消え、`favorites` フォルダは手順3で削除します。

## よくある質問

**Ctrl+Alt+V を押しても開かない**
ほかのアプリが同じキーを使っていると、起動時に「ホットキー Ctrl+Alt+V を登録できませんでした」と通知が出ます。上の「ショートカットキーを変える」で別のキーにしてください。それまではトレイのアイコンをクリックして開けます。

**2つ起動してしまった？**
ClipEdit は1つしか起動しません。もう一度 exe を起動すると、すでに動いているほうの編集ウィンドウが開きます。
「ClipEdit はすでに動いているようですが、応答しません」と出たときは、タスクマネージャーで clipedit.exe を終了してから、起動し直してください。

**お気に入りに追加できない・「お気に入りを整理…」でフォルダが開かない**
`clipedit.exe` を `C:\Program Files` に置いていると、ふつうに起動したアプリからは書き込めないので、お気に入りの追加が失敗します（`favorites` フォルダがないときは、フォルダを作れずに「お気に入りを整理…」も失敗します）。自分のフォルダへ移してください。

1. トレイのアイコンを右クリックして「終了」を選ぶ
2. ClipEdit のフォルダごと、自分のフォルダ（例：`C:\Users\<ユーザー名>\Apps\ClipEdit\`）へ移す
3. 移した先の `clipedit.exe` を起動する
4. 「ログイン時に起動」を使っていたときは、トレイのメニューでもう一度選び直す（新しい場所で登録し直されます）

**Mac や Linux で使えますか**
Windows 専用です。
