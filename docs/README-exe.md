# ClipEdit（配布版）

コピーした文字を、ショートカットキーひとつで開いて直せる Windows 用の小さなツールです。
直して Ctrl+Enter を押すとクリップボードが書き換わるので、あとは貼りたい場所で Ctrl+V を押すだけです。

- インストール不要。`clipedit.exe` 1つで動きます（ランタイムなどの追加も不要）
- ネットワークには一切つながりません。ログも残しません

## 動作環境

- Windows 10（バージョン 1703 以降）/ Windows 11、64bit

## はじめに

1. `clipedit.exe` を、自分だけが使うフォルダに置きます（例：`C:\Users\<ユーザー名>\Apps\ClipEdit\`）
2. `clipedit.exe` をダブルクリックして起動します
3. 画面右下のタスクトレイに、青いクリップボードのアイコンが出れば準備完了です

置き場所について：

- 「ダウンロード」フォルダや、ほかの人も書き込めるフォルダに置いたまま使うのは避けてください
- Windows 11 では、アイコンは最初「^」の中に隠れています。タスクバーへドラッグすると、いつも見えるようになります

### 「WindowsによってPCが保護されました」と出たら

この exe にはデジタル署名がないため、ダウンロードして最初に起動したときに、この画面が出ることがあります。
入手元が信頼できる場合は、「詳細情報」→「実行」で起動できます。

GitHub の Releases ページから入手した場合は、そのページに書いてある手順（`SHA256SUMS.txt` との照合など）で、ファイルが書き換えられていないことを確かめられます。

## 使い方

1. 直したい文字をコピーする
2. **Ctrl+Alt+V** を押す（マウスのある画面の中央に、編集ウィンドウが開きます）
3. 直して **Ctrl+Enter** を押す（クリップボードが書き換わり、ウィンドウが閉じます）
4. 貼りたい場所で **Ctrl+V** を押す

キーの一覧：

- Ctrl+Alt+V：編集ウィンドウを開く
- Ctrl+Enter：クリップボードに書き込んで閉じる
- Esc / × ボタン：書き込まずに閉じる
- Ctrl+A：すべて選択
- Ctrl+Backspace：直前の1語を消す
- Ctrl+Z：元に戻す

- 開いている間にもう一度 Ctrl+Alt+V を押しても、編集中の内容は消えません
- クリップボードが画像などテキスト以外のときは、空の状態で開きます（タイトルに「(テキストなし)」と出ます）
- 閉じると、編集欄の内容は消えます。次に開くときは、そのときのクリップボードを読み直します
- 改行のないとても長い行（5,000 文字を超えるもの）があるときは、折り返さずに横スクロールで表示します

### タスクトレイのメニュー

アイコンを左クリックすると、編集ウィンドウが開きます。右クリックすると、次のメニューが出ます。

- **開く**：編集ウィンドウを開く
- **設定を読み直す**：`config.toml` の変更を反映します（書き方が違う・新しいキーがほかのアプリに使われているときは、それまでのキーのまま使えます）
- **ログイン時に起動**：チェックすると、Windows にサインインしたときに自動で起動します
- **終了**：ClipEdit を終了します

exe を別の場所へ移したときは、「ログイン時に起動」のチェックが外れた表示になります。もう一度選ぶと、新しい場所で登録し直します。

## ショートカットキーを変える

同梱の `config.example.toml` の名前を `config.toml` に変え、メモ帳で開いて `hotkey` の行を書き換えるのがいちばん簡単です。
自分で作る場合は、`clipedit.exe` と同じフォルダに `config.toml` という名前のテキストファイルを作り、次のように書きます。

```toml
hotkey = "Ctrl+Shift+E"
```

- 修飾キー：`Ctrl` / `Alt` / `Shift` / `Win`（1つ以上必要。大文字小文字は区別しません）
- キー：`A`〜`Z`、`0`〜`9`、`F1`〜`F24`、`Space`、`Insert`
- 文字コードは UTF-8 で保存してください（Windows 11 のメモ帳なら、そのまま保存で UTF-8 になります）
- 変更は、トレイのメニューの「設定を読み直す」を選ぶと反映されます（起動し直しても反映されます）

書き方が違う・ファイルが大きすぎる（64KB 超）、といった場合は、既定の Ctrl+Alt+V で起動し、トレイから通知でお知らせします。
ほかのアプリが同じキーを使っているときは、ホットキーなしで起動して通知を出します。その間もトレイのアイコンをクリックすれば開けます。

## パスワードとプライバシー

- パスワード管理ソフトが「クリップボード履歴に残さない」印を付けてコピーした文字は、ClipEdit で書き戻すときにも同じ印を付け直します。Win+V の履歴やクラウド同期には残りません
- 閉じると、編集欄の内容と「元に戻す」の履歴を消します
- 通信はしません。PC にファイルを作ることもありません

## アンインストール

1. タスクトレイのメニューで「ログイン時に起動」のチェックを外す
2. 「終了」で ClipEdit を終了する
3. `clipedit.exe`（と、作っていれば `config.toml`）を削除する

ClipEdit が PC に残すのは、「ログイン時に起動」をオンにしたときのレジストリの値（`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` の `ClipEdit`）だけです。手順1でチェックを外すと消えます。

## よくある質問

**Ctrl+Alt+V を押しても開かない**
ほかのアプリが同じキーを使っていると、起動時に「ホットキーを登録できませんでした」と通知が出ます。上の「ショートカットキーを変える」で別のキーにしてください。それまではトレイのアイコンをクリックして開けます。

**2つ起動してしまった？**
ClipEdit は1つしか起動しません。もう一度 exe を起動すると、すでに動いているほうの編集ウィンドウが開きます。
「ClipEdit はすでに動いているようですが、応答しません」と出たときは、タスクマネージャーで clipedit.exe を終了してから、起動し直してください。

**Mac や Linux で使えますか**
Windows 専用です。
