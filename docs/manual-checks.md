# 手で確かめる項目（配布前）

自動テストにできない動作を、配布前に手で確かめる手順。台帳 `docs/tech-debt.md` の D7・D8 にあたる。
各項目に「期待する結果」を書いてある。結果が違ったら、台帳に新しい行を足す。

## 準備

1. `pwsh -NoProfile -File tools/build-release.ps1` で配布用の exe を作る（`target\release\clipedit.exe`）
2. 常駐している ClipEdit があれば、トレイの右クリック →「終了」で止める
3. exe と同じフォルダに `config.toml` があれば、別の名前に変えて退避しておく（項目によって書き換えるため）
4. クリップボードの中身は書き換わる。消えて困るものはコピーしておかない
5. `target\release\clipedit.exe` を起動する

覚えておく値：編集ウィンドウは 800×500（100% のとき）を表示倍率に合わせて広げ、作業領域より大きければ縮める。文字は「BIZ UDゴシック」の 11pt。

---

## D7 表示倍率の違うモニターをまたぐ

2台のモニターの表示倍率を変える（例：1台目 100%、2台目 150%）。設定 → システム → ディスプレイ →「拡大/縮小」。
モニターが1台しかないときは、D7-5 だけ確かめられる（テレビや「ワイヤレスディスプレイ」で2台目を足してもよい）。

| No | 操作 | 期待する結果 |
|---|---|---|
| D7-1 | マウスを 100% のモニターに置き、ホットキーで開く | そのモニターの作業領域の中央に、800×500 で開く |
| D7-2 | Esc で閉じ、マウスを 150% のモニターに移して開く | 150% のモニターの中央に、1200×750 で開く。文字が大きくなり、にじまない |
| D7-3 | 開いたまま、タイトルバーをつかんで 100% のモニターへ引きずる | 半分を越えたところで、ウィンドウが 800×500 相当に縮み、文字も小さくなる。カーソルとタイトルバーの位置がずれない |
| D7-4 | そのまま 150% のモニターへ戻す | 1200×750 相当に戻り、文字も大きくなる。行き来を繰り返しても大きさが少しずつ変わっていかない |
| D7-5 | 開いたまま、そのモニターの表示倍率を変える（100% → 150% → 100%） | 倍率を変えるたびに、ウィンドウと文字の大きさが追従する |
| D7-6 | 作業領域の狭いモニター（またはタスクバーを縦に置いたモニター）で開く | 作業領域からはみ出さず、タスクバーに重ならない |
| D7-7 | 2台目のモニターで開いたまま、そのモニターを外す（ケーブルを抜く、または「表示画面を複製/1のみに表示」） | ウィンドウが残ったモニターに移り、大きさと文字が残ったモニターの倍率に合う。Esc で閉じて開き直しても正しい位置に出る |

確かめたあと、編集・Ctrl+Enter の書き込みもふだん通り動くことを見ておく。

## D8 そのほか手で確かめる動作

### D8-1 IME で変換中の Enter / Esc

IME をオンにし、編集欄に「にほんご」と打って、変換を確定しない状態にする。

| No | 操作 | 期待する結果 |
|---|---|---|
| D8-1a | 変換中に Enter | 変換が確定するだけ。ウィンドウは閉じず、クリップボードも変わらない |
| D8-1b | 変換中に Esc | 変換が取り消されるだけ（IME の動作）。ウィンドウは閉じない |
| D8-1c | 確定したあとに Esc | ウィンドウが閉じる。クリップボードは開く前のまま |
| D8-1d | 変換中に Ctrl+Enter | クリップボードに書き込まない（未確定の文字を書き込まない）。何が起きたかを記録しておく |
| D8-1e | 変換中に Ctrl+Backspace | □ が入らない。IME の中の文字か、確定済みの1語が消える。どちらだったかを記録しておく |
| D8-1f | 確定してから Ctrl+Enter し、メモ帳に Ctrl+V | 確定した日本語がそのまま貼れる |

Microsoft IME で確かめる。ほかの IME（Google 日本語入力など）を使っているなら、そちらでも同じことをする。

### D8-2 ツールチップと通知の見た目

| No | 操作 | 期待する結果 |
|---|---|---|
| D8-2a | トレイのアイコンにマウスを重ねる | 「ClipEdit (Ctrl+Alt+V)」と出る |
| D8-2b | `config.toml` に `hotkey = " alt + ctrl + q "`（わざと小文字・空白入り・順番違い）と書き、右クリック →「設定を読み直す」 | 通知「ClipEdit: 設定を読み直しました」「ホットキーは Ctrl+Alt+Q です」が出る。ツールチップも「ClipEdit (Ctrl+Alt+Q)」に変わる（書いたとおりではなく決まった書き方。台帳 D42）。通知のアイコンは警告ではなく情報（i）|
| D8-2c | D8-2b のあと、`hotkey = "Ctrl+Nope"` と書いて読み直す | 通知の1行目に書き方の誤り、2行目に「ホットキーは Ctrl+Alt+Q のままです」が出る。2行に分かれて表示される。Ctrl+Alt+Q で開ける（台帳 D36） |
| D8-2c2 | `hotkey = ` とだけ書いて（値なし）読み直す | 通知の1行目が「config.toml を読めませんでした: 1 行目: …」の1行で、toml の元の行や ^ の図は出ない。最後の行のホットキーの知らせまで切れずに出る |
| D8-2d | `hotkey = "Ctrl+Alt+Q"` で読み直したあと、ほかのアプリに Ctrl+Alt+V を取らせ（下の「ホットキーを取っておく方法」）、`hotkey = "Ctrl+Alt+V"` にして読み直す | 通知「ホットキー Ctrl+Alt+V を登録できませんでした。Ctrl+Alt+Q のまま使えます。」が出る。ツールチップは「ClipEdit (Ctrl+Alt+Q)」のままで、Ctrl+Alt+Q で開ける（台帳 D36） |
| D8-2d2 | Ctrl+Alt+V を取らせたまま、`hotkey = "Ctrl+Alt+V"` で ClipEdit を終了して起動し直す | 通知「ホットキー Ctrl+Alt+V を登録できませんでした。トレイアイコンから開けます。」が出る。ツールチップが「ClipEdit (ホットキーなし)」になる。アイコンのクリックで開ける |
| D8-2e | D8-2c の設定のまま終了し、起動し直す | 通知「ClipEdit: 設定を既定値で起動しました」が出る |
| D8-2f | 右クリックメニューを出す | 「開く」「ログイン時に起動」「設定を読み直す」「終了」が並び、文字が切れていない。メニューの外をクリックすると閉じる |

どの通知も、日本語が文字化けせず、文が途中で切れていないことを見る。アイコンは、うまくいった知らせ（D8-2b）だけが情報、それ以外は警告。
通知が出ないときは、まず「応答不可（集中モード）」がオフになっているかを確かめる（オンだと通知センターにだけ入る）。

終わったら `config.toml` を元に戻して「設定を読み直す」。

**ホットキーを取っておく方法**：PowerShell を別に開いて次を貼る。Enter を押すまで Ctrl+Alt+V を押さえておく。

```powershell
Add-Type -Namespace W -Name U -MemberDefinition '[DllImport("user32.dll")] public static extern bool RegisterHotKey(System.IntPtr h, int id, uint mods, uint vk); [DllImport("user32.dll")] public static extern bool UnregisterHotKey(System.IntPtr h, int id);'
[W.U]::RegisterHotKey([IntPtr]::Zero, 1, 0x4003, 0x56)   # Ctrl+Alt+V（MOD_NOREPEAT 付き）。True なら取れた
Read-Host 'Enter で放す'
[W.U]::UnregisterHotKey([IntPtr]::Zero, 1)
```

ClipEdit が先に Ctrl+Alt+V を登録していると False になる。そのときは先に `config.toml` を別のキーにして読み直してから、上を実行する。

### D8-4 改行のない長い行（監査 S10）

| No | 操作 | 期待する結果 |
|---|---|---|
| D8-4a | PowerShell で `Set-Clipboard ('x' * 4999)` のあと、ホットキーで開く | 1 秒以内に開き、折り返して表示される。タイトルに「折り返さずに表示」は出ない |
| D8-4b | `Set-Clipboard ('x' * 200000)` のあと開く | 1 秒以内に開き、横スクロールバーが出て折り返さない。タイトルに「(長い行があるため折り返さずに表示)」と出る。Ctrl+Enter で書き込め、Esc で閉じられる |
| D8-4c | D8-4b のあと、`Set-Clipboard "短い行`r`n2行目"` にして開く | 折り返す表示に戻り、タイトルの注記が消える |
| D8-4d | `Set-Clipboard ('x' * 5000)` で開き、開くまでの時間を見る | 上限ちょうどは折り返し、すぐに開く（2026-10-18 に測ったときは 0.3 秒。台帳 D46）。1 秒以上かかるなら、`WRAP_LIMIT` を小さくする |

### D8-3 エクスプローラーを再起動したあとのアイコン

| No | 操作 | 期待する結果 |
|---|---|---|
| D8-3a | タスクマネージャーで「エクスプローラー」を選び「再起動」（または `taskkill /f /im explorer.exe` のあと `start explorer`） | 数秒でトレイにアイコンが戻る。アイコンが2つにならない |
| D8-3b | 戻ったアイコンにマウスを重ねる | ツールチップが再起動前と同じ（「設定を読み直す」で変えていればその値） |
| D8-3c | 戻ったアイコンのクリック・右クリックメニュー・ホットキー | どれも動く |
| D8-3d | 「終了」を選ぶ | アイコンが消え、トレイにマウスを重ねても幽霊のアイコンが残らない |

### D8-4 高い表示倍率

設定 → ディスプレイの「拡大/縮小」を 125%・150%・175%・200% に変え、それぞれで確かめる。
倍率を変えたら、ClipEdit を一度終了して起動し直したときと、起動したままのときの両方を見る。

| No | 操作 | 期待する結果 |
|---|---|---|
| D8-4a | トレイのアイコンを見る | ぼやけず、ほかのアイコンと同じ大きさ（150% で 24px） |
| D8-4b | ホットキーで開く | 800×500 × 倍率の大きさで開き、文字がにじまない（ぼやけるなら DPI の設定が効いていない） |
| D8-4c | 編集欄に長い行と多くの行を入れる | 横は折り返され、縦はスクロールバーが出る。スクロールバーと文字の大きさが合っている |
| D8-4d | 右クリックメニューと通知を出す | 倍率に合った大きさで、文字が切れていない |
| D8-4e | 小さな画面（1366×768 など）で 200% にして開く | 作業領域からはみ出さない |
