# 技術負債の台帳

わかっている負債を1件1行で記録する。直したら行を消さずに「状態」を「解消」にし、コミットを書く。

## 見直しのしかた

機能を足したあと・配布用 zip を作る前・それ以外は月に1回、次を行う。

1. `pwsh -NoProfile -File tools/debt-scan.ps1` を実行する（結果は `target/debt/` に保存され、`docs/debt-baseline.json` との増減が出る）
2. Claude Code に次の依頼文を送る

```
tools/debt-scan.ps1 を実行し、結果と docs/tech-debt.md を読んでください。
1. 基準値から増えた兆候の原因を調べる
2. コードを読んで、台帳にない負債を探す（重複したコード、長すぎる関数、テストのない分岐、ドキュメントとのずれ）
3. 見つけたものを台帳に追記し、直す順番を提案する
コードはまだ直さないでください。
```

3. 増えた兆候を直したか、台帳に載せて受け入れたら、`pwsh -NoProfile -File tools/debt-scan.ps1 -UpdateBaseline` で基準値を更新してコミットする

## 保留した機能の設計（D31）

2026-10-16 に利用者と決めた設計。再開するときは、ここから始める（決め直してもよい）。

- **キー**：Ctrl+J で改行をつなげる、Ctrl+T で空白と空の行を消す。どちらも今の編集欄では何も起きないキー
- **効く範囲**：文字を選んでいればその部分、選んでいなければ全文。整形した範囲を選んだ状態にする。`EM_REPLACESEL` の元に戻す付きで置き換え、Ctrl+Z で戻せる（標準の編集欄なので1回だけ）
- **改行をつなげる**：空の行（空白だけの行も）は段落の区切りとして残し、段落の中の改行だけを消す。つなぎ目の前後の空白は消す。前後どちらかが日本語（ひらがな・カタカナ・漢字・全角の記号・半角カナ）なら空白なしでつなぎ、両方とも英数字なら空白1つでつなぐ。行末のハイフンは残す。末尾の改行は残す
- **空白と空の行を消す**：各行の前後の空白（半角・全角の空白とタブ）を消す。2行以上続く空の行は1行にする。先頭と末尾の空の行は消す（字下げの全角空白も消える）
- **文字数の表示**：編集ウィンドウの下にステータスバーを足す。左に「123 文字 / 4 行」、選んでいるときは「選択 12 文字 / 全体 123 文字 / 4 行」。右に「Ctrl+J: 改行をつなげる　Ctrl+T: 空白を消す」。タイトルバーはキーの説明と書き込み失敗の理由で長くなるため使わない
- **数え方**：改行を数えない。文字数は Unicode の文字（コードポイント）の数で、👍 は1、家族の絵文字は部品の数（5）。行数は改行の数＋1、空なら 0
- **表示の更新**：文字を打ったとき（`EN_CHANGE`）、選択を変えたとき（メッセージループで編集欄宛てのキーとマウスを処理したあと）、`show_with` と整形のあと。複数行の編集欄は `WM_SETTEXT` では `EN_CHANGE` を出さないので、`show_with` では自分で更新する
- **ファイル**：整形と数える処理は `src/textops.rs`（文字列を受け取って返すだけの関数。普通のテストで確かめる）。`editor.rs` にはキー・ステータスバー・更新だけを足す（D30 の方針）。ステータスバーの文字も表示倍率に合わせる
- **テスト**：`textops` は普通のテスト（日本語・英語・混在、空の行、CRLF / LF / CR、字下げ、空の文字列、絵文字）。実機のテストで、キーで中身が変わること、Ctrl+Z で戻ること、選択範囲だけ変わること、ステータスバーの数字
- **文書**：README と配布用 README のキーの一覧、設計書、`docs/manual-checks.md`（IME で変換中に Ctrl+J / Ctrl+T を押したとき、ステータスバーの見た目）
- **見送った案**：全角と半角の変換（利用者が選ばなかった）
