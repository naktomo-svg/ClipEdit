# ClipEdit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** クリップボードのテキストをホットキー一発で表示・編集し、Ctrl+Enter でクリップボードに書き戻す常駐型 Windows ユーティリティを Rust で作る。

**Architecture:** Win32 API を `windows` クレートで直接呼ぶ単一の exe。表示しない本体ウィンドウがホットキーとトレイのメッセージを受け、常に1つだけ存在する編集ウィンドウ（複数行 EDIT コントロール）を表示／非表示で切り替える。純粋な処理（ホットキー文字列の解釈、設定、改行の統一、位置計算）は関数に分けて単体テストし、OS に触れる部分は `#[ignore]` の結合テストと手動テストで確かめる。

**Tech Stack:** Rust 2024 edition（cargo 1.99）、`windows` 0.62、`serde` 1、`toml` 1

**Spec:** `docs/superpowers/specs/2026-10-15-clipedit-design.md`

## Global Constraints

- 対象 OS は Windows 10 / 11。依存クレートは `windows`、`serde`、`toml` の3つだけ
- 既定のホットキーは `Ctrl+Alt+V`。設定ファイルは exe と同じフォルダの `config.toml`（キーは `hotkey`）
- 確定は Ctrl+Enter（クリップボードを書き換えて隠す）、取り消しは Esc と ×（書き換えずに隠す）
- 二重起動防止の Mutex 名は `Local\ClipEdit-SingleInstance`
- 自動起動は `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` の値 `ClipEdit`（exe のフルパスを引用符で囲む）
- クリップボードを開くときは 50ms 間隔で最大 5 回まで試す
- 画面に出す文言は日本語
- リリースビルドではコンソールを出さない（`#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]`）
- この計画のコードは、計画を作る段階で作業用フォルダでビルド済み。`cargo test`（16件）と `cargo test -- --ignored --test-threads=1`（3件）がすべて通り、`cargo clippy` の警告が 0 件であることを確認している

## Review Focus

仕様には書かれていないが使う人が出会いやすい状況と、そのとき期待される動き:

1. **編集中にもう一度ホットキーを押す** → 編集中の内容を消さず、ウィンドウを前面に出すだけ（Task 6 の `open_while_visible_keeps_edits`）
2. **32,767 文字を超える長いテキストをコピーしている**（EDIT コントロールの既定の上限）→ 切れずに全部表示される（Task 6 の `shows_text_longer_than_default_edit_limit`）
3. **改行が LF だけ／CR だけのテキスト**（Web ページや Mac・Linux 由来）→ 1行に詰まらず改行として表示される（Task 6 の `normalizes_all_newline_kinds_to_crlf`）
4. **IME で変換中に Enter や Esc を押す** → 変換の確定・取り消しだけが起き、ウィンドウは閉じず、書き込みも起きない（Task 6 の `handle_key` は VK_PROCESSKEY を無視する。Task 7 の手動テスト 3）
5. **エクスプローラーの再起動、高 DPI や小さい画面** → トレイアイコンが付け直される（Task 7 の手動テスト 9）。ウィンドウは画面からはみ出さず、文字もぼやけない（Task 6 の `shrinks_to_small_work_area`、Task 7 の手動テスト 10）

```rust
use serde::Deserialize;
use std::path::{Path, PathBuf};

pub const DEFAULT_HOTKEY: &str = "Ctrl+Alt+V";

#[derive(Debug, Clone, PartialEq, Deserialize)]
#[serde(default)]
pub struct Config {
    pub hotkey: String,
}

impl Default for Config {
    fn default() -> Self {
        Config {
            hotkey: DEFAULT_HOTKEY.to_string(),
        }
    }
}

/// TOML の文字列を解釈する。書式が不正なら Err にエラー内容を返す。
pub fn parse(text: &str) -> Result<Config, String> {
    toml::from_str(text).map_err(|e| e.to_string())
}

/// 設定ファイルを読む。ファイルが無ければ既定値、壊れていれば既定値と警告文を返す。
pub fn load(path: &Path) -> (Config, Option<String>) {
    match std::fs::read_to_string(path) {
        Err(_) => (Config::default(), None),
        Ok(text) => match parse(&text) {
            Ok(config) => (config, None),
            Err(e) => (
                Config::default(),
                Some(format!("config.toml を読めませんでした: {e}")),
            ),
        },
    }
}

/// exe と同じフォルダの config.toml。
pub fn default_path() -> PathBuf {
    std::env::current_exe()
        .ok()
        .and_then(|exe| exe.parent().map(|dir| dir.join("config.toml")))
        .unwrap_or_else(|| PathBuf::from("config.toml"))
}
```

```rust
use windows::Win32::Foundation::HWND;
use windows::Win32::UI::Input::KeyboardAndMouse::{
    HOT_KEY_MODIFIERS, MOD_ALT, MOD_CONTROL, MOD_NOREPEAT, MOD_SHIFT, MOD_WIN, RegisterHotKey,
    UnregisterHotKey,
};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct HotKey {
    pub mods: u32,
    pub vk: u32,
}

/// "Ctrl+Alt+V" のような文字列を解釈する。大文字小文字は区別しない。
pub fn parse(text: &str) -> Result<HotKey, String> {
    let mut mods = 0u32;
    let mut vk = None;
    for part in text.split('+').map(str::trim) {
        match part.to_ascii_lowercase().as_str() {
            "ctrl" | "control" => mods |= MOD_CONTROL.0,
            "alt" => mods |= MOD_ALT.0,
            "shift" => mods |= MOD_SHIFT.0,
            "win" => mods |= MOD_WIN.0,
            "" => return Err(format!("ホットキー \"{text}\" の書き方が正しくありません")),
            key => {
                if vk.is_some() {
                    return Err(format!("ホットキー \"{text}\" にキーが2つ以上あります"));
                }
                vk = Some(parse_key(key)?);
            }
        }
    }
    let vk = vk.ok_or_else(|| format!("ホットキー \"{text}\" にキーがありません"))?;
    if mods == 0 {
        return Err(format!(
            "ホットキー \"{text}\" には Ctrl / Alt / Shift / Win のどれかが必要です"
        ));
    }
    Ok(HotKey { mods, vk })
}

fn parse_key(key: &str) -> Result<u32, String> {
    let upper = key.to_ascii_uppercase();
    let bytes = upper.as_bytes();
    if bytes.len() == 1 && (bytes[0].is_ascii_uppercase() || bytes[0].is_ascii_digit()) {
        return Ok(bytes[0] as u32);
    }
    if let Some(n) = upper.strip_prefix('F').and_then(|n| n.parse::<u32>().ok())
        && (1..=24).contains(&n)
    {
        return Ok(0x70 + n - 1); // VK_F1 = 0x70
    }
    match upper.as_str() {
        "SPACE" => Ok(0x20),
        "INSERT" => Ok(0x2D),
        _ => Err(format!("不明なキー \"{key}\" です")),
    }
}

pub fn register(hwnd: HWND, id: i32, hotkey: HotKey) -> windows::core::Result<()> {
    unsafe {
        RegisterHotKey(
            Some(hwnd),
            id,
            HOT_KEY_MODIFIERS(hotkey.mods | MOD_NOREPEAT.0),
            hotkey.vk,
        )
    }
}

pub fn unregister(hwnd: HWND, id: i32) {
    unsafe {
        let _ = UnregisterHotKey(Some(hwnd), id);
    }
}
```

```rust
use std::time::Duration;
use windows::Win32::Foundation::{GlobalFree, HANDLE, HGLOBAL, HWND};
use windows::Win32::System::DataExchange::{
    CloseClipboard, EmptyClipboard, GetClipboardData, IsClipboardFormatAvailable, OpenClipboard,
    SetClipboardData,
};
use windows::Win32::System::Memory::{GMEM_MOVEABLE, GlobalAlloc, GlobalLock, GlobalUnlock};
use windows::Win32::System::Ole::CF_UNICODETEXT;

const RETRIES: u32 = 5;
const RETRY_WAIT: Duration = Duration::from_millis(50);

/// 開いている間だけ存在し、drop で CloseClipboard する。
struct OpenGuard;

impl OpenGuard {
    fn open(owner: Option<HWND>) -> Result<OpenGuard, String> {
        for attempt in 0..RETRIES {
            if unsafe { OpenClipboard(owner) }.is_ok() {
                return Ok(OpenGuard);
            }
            if attempt + 1 < RETRIES {
                std::thread::sleep(RETRY_WAIT);
            }
        }
        Err("クリップボードを開けませんでした".to_string())
    }
}

impl Drop for OpenGuard {
    fn drop(&mut self) {
        unsafe {
            let _ = CloseClipboard();
        }
    }
}

/// クリップボードのテキストを読む。テキストが無ければ Ok(None)。
pub fn read_text() -> Result<Option<String>, String> {
    let _guard = OpenGuard::open(None)?;
    unsafe {
        if IsClipboardFormatAvailable(CF_UNICODETEXT.0 as u32).is_err() {
            return Ok(None);
        }
        let handle = GetClipboardData(CF_UNICODETEXT.0 as u32).map_err(|e| e.message())?;
        let global = HGLOBAL(handle.0);
        let ptr = GlobalLock(global) as *const u16;
        if ptr.is_null() {
            return Err("クリップボードの内容を読めませんでした".to_string());
        }
        let mut len = 0;
        while *ptr.add(len) != 0 {
            len += 1;
        }
        let text = String::from_utf16_lossy(std::slice::from_raw_parts(ptr, len));
        let _ = GlobalUnlock(global);
        Ok(Some(text))
    }
}

/// クリップボードをテキストで置き換える。owner はクリップボードの所有者にするウィンドウ。
pub fn write_text(owner: Option<HWND>, text: &str) -> Result<(), String> {
    let wide: Vec<u16> = text.encode_utf16().chain(Some(0)).collect();
    let _guard = OpenGuard::open(owner)?;
    unsafe {
        EmptyClipboard().map_err(|e| e.message())?;
        let global = GlobalAlloc(GMEM_MOVEABLE, wide.len() * 2).map_err(|e| e.message())?;
        let ptr = GlobalLock(global) as *mut u16;
        if ptr.is_null() {
            let _ = GlobalFree(Some(global));
            return Err("メモリを確保できませんでした".to_string());
        }
        std::ptr::copy_nonoverlapping(wide.as_ptr(), ptr, wide.len());
        let _ = GlobalUnlock(global);
        if let Err(e) = SetClipboardData(CF_UNICODETEXT.0 as u32, Some(HANDLE(global.0))) {
            // 失敗したときだけ自分で解放する。成功したらメモリはシステムのもの。
            let _ = GlobalFree(Some(global));
            return Err(e.message());
        }
        Ok(())
    }
}
```

```rust
    HKEY_CURRENT_USER, REG_SZ, RRF_RT_REG_SZ, RegDeleteKeyValueW, RegGetValueW, RegSetKeyValueW,
};
use windows::core::{PCWSTR, w};

const RUN_KEY: PCWSTR = w!("Software\\Microsoft\\Windows\\CurrentVersion\\Run");
const VALUE_NAME: PCWSTR = w!("ClipEdit");

/// Run キーに登録するコマンド行。パスに空白があっても動くよう引用符で囲む。
pub fn command_line(exe: &Path) -> String {
    format!("\"{}\"", exe.display())
}

pub fn is_enabled() -> bool {
    unsafe {
        RegGetValueW(
            HKEY_CURRENT_USER,
            RUN_KEY,
            VALUE_NAME,
            RRF_RT_REG_SZ,
            None,
            None,
            None,
        )
    }
    .is_ok()
}

pub fn set(enabled: bool) -> Result<(), String> {
    if enabled {
        let exe = std::env::current_exe().map_err(|e| e.to_string())?;
        let value: Vec<u16> = command_line(&exe).encode_utf16().chain(Some(0)).collect();
        let result = unsafe {
            RegSetKeyValueW(
                HKEY_CURRENT_USER,
                RUN_KEY,
                VALUE_NAME,
                REG_SZ.0,
                Some(value.as_ptr() as *const _),
                (value.len() * 2) as u32,
            )
        };
        result.ok().map_err(|e| e.message())
    } else {
        let result = unsafe { RegDeleteKeyValueW(HKEY_CURRENT_USER, RUN_KEY, VALUE_NAME) };
        if result == ERROR_FILE_NOT_FOUND {
            return Ok(());
        }
        result.ok().map_err(|e| e.message())
    }
}
```

```rust
/// トレイアイコンから本体ウィンドウに届くメッセージ。
pub const WM_TRAY: u32 = WM_APP + 1;
pub const CMD_OPEN: usize = 1;
pub const CMD_AUTOSTART: usize = 2;
pub const CMD_EXIT: usize = 3;

const ICON_ID: u32 = 1;

/// 固定長の UTF-16 配列に文字列を詰める（はみ出す分は切り捨て、末尾は必ず 0）。
pub fn copy_wide(dst: &mut [u16], src: &str) {
    let mut i = 0;
    for unit in src.encode_utf16() {
        if i + 1 >= dst.len() {
            break;
        }
        dst[i] = unit;
        i += 1;
    }
    dst[i] = 0;
}

fn base_data(hwnd: HWND) -> NOTIFYICONDATAW {
    NOTIFYICONDATAW {
        cbSize: std::mem::size_of::<NOTIFYICONDATAW>() as u32,
        hWnd: hwnd,
        uID: ICON_ID,
        ..Default::default()
    }
}

pub fn add(hwnd: HWND, tip: &str) -> Result<(), String> {
    let mut data = base_data(hwnd);
    data.uFlags = NIF_ICON | NIF_MESSAGE | NIF_TIP;
    data.uCallbackMessage = WM_TRAY;
    data.hIcon = unsafe { LoadIconW(None, IDI_APPLICATION) }.map_err(|e| e.message())?;
    copy_wide(&mut data.szTip, tip);
    if unsafe { Shell_NotifyIconW(NIM_ADD, &data) }.as_bool() {
        Ok(())
    } else {
        Err("トレイアイコンを追加できませんでした".to_string())
    }
}

pub fn remove(hwnd: HWND) {
    let data = base_data(hwnd);
    unsafe {
        let _ = Shell_NotifyIconW(NIM_DELETE, &data);
    }
}

/// トレイから通知バルーンを出す。
pub fn notify(hwnd: HWND, title: &str, message: &str) {
    let mut data = base_data(hwnd);
    data.uFlags = NIF_INFO;
    data.dwInfoFlags = NIIF_WARNING;
    copy_wide(&mut data.szInfoTitle, title);
    copy_wide(&mut data.szInfo, message);
    unsafe {
        let _ = Shell_NotifyIconW(NIM_MODIFY, &data);
    }
}

/// 右クリックメニューを出す。選ばれた項目は WM_COMMAND (CMD_*) で hwnd に届く。
pub fn show_menu(hwnd: HWND, autostart_on: bool) {
    unsafe {
        let Ok(menu) = CreatePopupMenu() else { return };
        let check = if autostart_on {
            MF_CHECKED
        } else {
            MF_UNCHECKED
        };
        let _ = AppendMenuW(menu, MF_STRING, CMD_OPEN, w!("開く"));
        let _ = AppendMenuW(
            menu,
            MF_STRING | check,
            CMD_AUTOSTART,
            w!("ログイン時に起動"),
        );
        let _ = AppendMenuW(menu, MF_SEPARATOR, 0, PCWSTR::null());
        let _ = AppendMenuW(menu, MF_STRING, CMD_EXIT, w!("終了"));
        let mut pt = POINT::default();
        let _ = GetCursorPos(&mut pt);
        // これをしないとメニューの外をクリックしても閉じない（Win32 の既知の作法）
        let _ = SetForegroundWindow(hwnd);
        let _ = TrackPopupMenu(menu, TPM_RIGHTBUTTON, pt.x, pt.y, Some(0), hwnd, None);
        let _ = PostMessageW(Some(hwnd), WM_NULL, WPARAM(0), LPARAM(0));
        let _ = DestroyMenu(menu);
    }
}
```

```rust
const CLASS_NAME: PCWSTR = w!("ClipEditEditor");
const EDIT_ID: i32 = 100;
const BASE_WIDTH: i32 = 800;
const BASE_HEIGHT: i32 = 500;
const FONT_POINTS: i32 = 11;
const TITLE: &str = "ClipEdit  (Ctrl+Enter: クリップボードに書き込む / Esc: 閉じる)";

thread_local! {
    // show_with が位置を決めている最中は WM_DPICHANGED の推奨位置を使わない
    static POSITIONING: Cell<bool> = const { Cell::new(false) };

/// 改行を CRLF にそろえる（LF だけ・CR だけの改行も EDIT コントロールで改行として見えるように）。
pub fn normalize_newlines(text: &str) -> String {
    text.replace("\r\n", "\n")
        .replace('\r', "\n")
        .replace('\n', "\r\n")
}

/// 読み込み結果に応じたウィンドウタイトル。
pub fn title_for(content: &Result<Option<String>, String>) -> String {
    match content {
        Ok(Some(_)) => TITLE.to_string(),
        Ok(None) => format!("{TITLE}  (テキストなし)"),
        Err(e) => format!("{TITLE}  - {e}"),
    }
}

/// 作業領域 work の中央に置く矩形 (x, y, 幅, 高さ)。作業領域より大きければ縮める。
pub fn center_rect(work: RECT, width: i32, height: i32) -> (i32, i32, i32, i32) {
    let w = width.min(work.right - work.left);
    let h = height.min(work.bottom - work.top);
    let x = work.left + (work.right - work.left - w) / 2;
    let y = work.top + (work.bottom - work.top - h) / 2;
    (x, y, w, h)
}

fn scale(value: i32, dpi: u32) -> i32 {
    value * dpi as i32 / 96
}

#[derive(Clone, Copy)]
pub struct Editor {
    hwnd: HWND,
    edit: HWND,
}

impl Editor {
    pub fn create(instance: HINSTANCE) -> windows::core::Result<Editor> {
        unsafe {
            let class = WNDCLASSW {
                lpfnWndProc: Some(wnd_proc),
                hInstance: instance,
                lpszClassName: CLASS_NAME,
                hCursor: LoadCursorW(None, IDC_ARROW)?,
                ..Default::default()
            };
            RegisterClassW(&class);
            let hwnd = CreateWindowExW(
                WINDOW_EX_STYLE::default(),
                CLASS_NAME,
                &HSTRING::from(TITLE),
                WS_OVERLAPPEDWINDOW,
                0,
                0,
                BASE_WIDTH,
                BASE_HEIGHT,
                None,
                None,
                Some(instance),
                None,
            )?;
            let style = WS_CHILD
                | WS_VISIBLE
                | WS_VSCROLL
                | WINDOW_STYLE((ES_MULTILINE | ES_AUTOVSCROLL | ES_WANTRETURN) as u32);
            let edit = CreateWindowExW(
                WS_EX_CLIENTEDGE,
                w!("EDIT"),
                PCWSTR::null(),
                style,
                0,
                0,
                0,
                0,
                Some(hwnd),
                Some(HMENU(EDIT_ID as usize as *mut _)),
                Some(instance),
                None,
            )?;
            // 既定の上限は 32,767 文字。0 を渡すと上限を最大にする
            SendMessageW(edit, EM_SETLIMITTEXT, Some(WPARAM(0)), Some(LPARAM(0)));
            apply_font(edit, GetDpiForWindow(hwnd));
            Ok(Editor { hwnd, edit })
        }
    }

    pub fn is_visible(&self) -> bool {
        unsafe { IsWindowVisible(self.hwnd).as_bool() }
    }

    /// すでに開いていれば前面に出すだけ（編集中の内容を消さない）。閉じていれば read で読み込んで開く。
    pub fn open(&self, read: impl FnOnce() -> Result<Option<String>, String>) {
        if self.is_visible() {
            self.activate();
        } else {
            self.show_with(read());
        }
    }

    pub fn show_with(&self, content: Result<Option<String>, String>) {
        let title = title_for(&content);
        let text = match content {
            Ok(Some(text)) => normalize_newlines(&text),
            _ => String::new(),
        };
        unsafe {
            let _ = SetWindowTextW(self.hwnd, &HSTRING::from(title));
            let _ = SetWindowTextW(self.edit, &HSTRING::from(text));
            SendMessageW(self.edit, EM_SETSEL, Some(WPARAM(0)), Some(LPARAM(-1)));

            let mut cursor = POINT::default();
            let _ = GetCursorPos(&mut cursor);
            let monitor = MonitorFromPoint(cursor, MONITOR_DEFAULTTONEAREST);
            let mut info = MONITORINFO {
                cbSize: std::mem::size_of::<MONITORINFO>() as u32,
                ..Default::default()
            };
            let _ = GetMonitorInfoW(monitor, &mut info);
            let (mut dpi_x, mut dpi_y) = (96u32, 96u32);
            let _ = GetDpiForMonitor(monitor, MDT_EFFECTIVE_DPI, &mut dpi_x, &mut dpi_y);
            let (x, y, w, h) = center_rect(
                info.rcWork,
                scale(BASE_WIDTH, dpi_x),
                scale(BASE_HEIGHT, dpi_x),
            );

            POSITIONING.with(|p| p.set(true));
            let _ = SetWindowPos(self.hwnd, None, x, y, w, h, SWP_NOZORDER);
            POSITIONING.with(|p| p.set(false));
            apply_font(self.edit, GetDpiForWindow(self.hwnd));
        }
        self.activate();
    }

    fn activate(&self) {
        unsafe {
            let _ = ShowWindow(self.hwnd, SW_SHOW);
            let _ = SetForegroundWindow(self.hwnd);
            let _ = SetFocus(Some(self.edit));
        }
    }

    pub fn hide(&self) {
        unsafe {
            let _ = ShowWindow(self.hwnd, SW_HIDE);
        }
    }

    pub fn text(&self) -> String {
        unsafe {
            let len = GetWindowTextLengthW(self.edit);
            let mut buf = vec![0u16; len as usize + 1];
            let copied = GetWindowTextW(self.edit, &mut buf);
            String::from_utf16_lossy(&buf[..copied as usize])
        }
    }

    pub fn set_title(&self, title: &str) {
        unsafe {
            let _ = SetWindowTextW(self.hwnd, &HSTRING::from(title));
        }
    }

    fn commit(&self) {
        match clipboard::write_text(Some(self.hwnd), &self.text()) {
            Ok(()) => self.hide(),
            Err(e) => self.set_title(&format!("{TITLE}  - 書き込み失敗: {e}")),
        }
    }

    /// メッセージループで TranslateMessage の前に呼ぶ。処理したキーなら true。
    /// IME で変換中の Enter / Esc は VK_PROCESSKEY として届くので、ここでは反応しない。
    pub fn handle_key(&self, msg: &MSG) -> bool {
        if msg.hwnd != self.edit || msg.message != WM_KEYDOWN {
            return false;
        }
        let ctrl = unsafe { GetKeyState(VK_CONTROL.0 as i32) } < 0;
        let key = msg.wParam.0 as u16;
        if key == VK_RETURN.0 && ctrl {
            self.commit();
            true
        } else if key == VK_ESCAPE.0 {
            self.hide();
            true
        } else if key == b'A' as u16 && ctrl {
            unsafe {
                SendMessageW(self.edit, EM_SETSEL, Some(WPARAM(0)), Some(LPARAM(-1)));
            }
            true
        } else {
            false
        }
    }
}

fn apply_font(edit: HWND, dpi: u32) {
    unsafe {
        let old = SendMessageW(edit, WM_GETFONT, None, None);
        let font = CreateFontW(
            -(FONT_POINTS * dpi as i32 / 72),
            0,
            0,
            0,
            FW_NORMAL.0 as i32,
            0,
            0,
            0,
            DEFAULT_CHARSET,
            OUT_DEFAULT_PRECIS,
            CLIP_DEFAULT_PRECIS,
            CLEARTYPE_QUALITY,
            (FIXED_PITCH.0 | FF_MODERN.0) as u32,
            w!("BIZ UDゴシック"),
        );
        SendMessageW(
            edit,
            WM_SETFONT,
            Some(WPARAM(font.0 as usize)),
            Some(LPARAM(1)),
        );
        if old.0 != 0 {
            let _ = DeleteObject(HGDIOBJ(HFONT(old.0 as *mut _).0));
        }
    }
}

extern "system" fn wnd_proc(hwnd: HWND, msg: u32, wparam: WPARAM, lparam: LPARAM) -> LRESULT {
    unsafe {
        match msg {
            WM_SIZE => {
                let width = (lparam.0 & 0xFFFF) as i32;
                let height = ((lparam.0 >> 16) & 0xFFFF) as i32;
                if let Ok(edit) = GetDlgItem(Some(hwnd), EDIT_ID) {
                    let _ = MoveWindow(edit, 0, 0, width, height, true);
                }
                LRESULT(0)
            }
            WM_CLOSE => {
                let _ = ShowWindow(hwnd, SW_HIDE);
                LRESULT(0)
            }
            WM_ACTIVATE => {
                if (wparam.0 & 0xFFFF) as u32 != WA_INACTIVE
                    && let Ok(edit) = GetDlgItem(Some(hwnd), EDIT_ID)
                {
                    let _ = SetFocus(Some(edit));
                }
                LRESULT(0)
            }
            WM_DPICHANGED => {
                if !POSITIONING.with(|p| p.get()) {
                    let r = &*(lparam.0 as *const RECT);
                    let _ = SetWindowPos(
                        hwnd,
                        None,
                        r.left,
                        r.top,
                        r.right - r.left,
                        r.bottom - r.top,
                        SWP_NOZORDER,
                    );
                }
                if let Ok(edit) = GetDlgItem(Some(hwnd), EDIT_ID) {
                    apply_font(edit, (wparam.0 & 0xFFFF) as u32);
                }
                LRESULT(0)
            }
            _ => DefWindowProcW(hwnd, msg, wparam, lparam),
        }
    }
}
```

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

mod autostart;
mod clipboard;
mod config;
mod editor;
mod hotkey;
mod tray;

use std::cell::Cell;
use windows::Win32::Foundation::{
    CloseHandle, ERROR_ALREADY_EXISTS, GetLastError, HANDLE, HWND, LPARAM, LRESULT, WPARAM,
};
use windows::Win32::System::LibraryLoader::GetModuleHandleW;
use windows::Win32::System::Threading::CreateMutexW;
use windows::Win32::UI::HiDpi::{
    DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2, SetProcessDpiAwarenessContext,
};
use windows::Win32::UI::WindowsAndMessaging::{
    CreateWindowExW, DefWindowProcW, DestroyWindow, DispatchMessageW, GetMessageW, MSG,
    PostQuitMessage, RegisterClassW, RegisterWindowMessageW, TranslateMessage, WINDOW_EX_STYLE,
    WINDOW_STYLE, WM_COMMAND, WM_DESTROY, WM_HOTKEY, WM_LBUTTONUP, WM_RBUTTONUP, WNDCLASSW,
};
use windows::core::{PCWSTR, w};

use editor::Editor;

const MAIN_CLASS: PCWSTR = w!("ClipEditMain");
const HOTKEY_ID: i32 = 1;

thread_local! {
    static EDITOR: Cell<Option<Editor>> = const { Cell::new(None) };
    static TASKBAR_CREATED: Cell<u32> = const { Cell::new(0) };
    static TRAY_TIP: Cell<&'static str> = const { Cell::new("ClipEdit") };
}

fn main() {
    let Some(mutex) = single_instance() else {
        return;
    };
    unsafe {
        let _ = SetProcessDpiAwarenessContext(DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2);
    }
    let instance = unsafe { GetModuleHandleW(None) }
        .expect("GetModuleHandleW")
        .into();
    let editor = Editor::create(instance).expect("編集ウィンドウを作れませんでした");
    EDITOR.with(|e| e.set(Some(editor)));

    let main = unsafe {
        let class = WNDCLASSW {
            lpfnWndProc: Some(main_proc),
            hInstance: instance,
            lpszClassName: MAIN_CLASS,
            ..Default::default()
        };
        RegisterClassW(&class);
        TASKBAR_CREATED.with(|t| t.set(RegisterWindowMessageW(w!("TaskbarCreated"))));
        // HWND_MESSAGE の窓は TaskbarCreated を受け取れないので、表示しない普通のウィンドウにする
        CreateWindowExW(
            WINDOW_EX_STYLE::default(),
            MAIN_CLASS,
            w!("ClipEdit"),
            WINDOW_STYLE::default(),
            0,
            0,
            0,
            0,
            None,
            None,
            Some(instance),
            None,
        )
    }
    .expect("本体ウィンドウを作れませんでした");

    let (config, config_warning) = config::load(&config::default_path());
    let (hotkey, hotkey_warning) = match hotkey::parse(&config.hotkey) {
        Ok(hk) => (hk, None),
        Err(e) => (hotkey::parse(config::DEFAULT_HOTKEY).unwrap(), Some(e)),
    };
    let hotkey_text = if hotkey_warning.is_some() {
        config::DEFAULT_HOTKEY.to_string()
    } else {
        config.hotkey.clone()
    };
    TRAY_TIP.with(|t| {
        t.set(Box::leak(
            format!("ClipEdit ({hotkey_text})").into_boxed_str(),
        ))
    });

    let _ = tray::add(main, TRAY_TIP.with(|t| t.get()));
    if let Some(warning) = config_warning.or(hotkey_warning) {
        tray::notify(main, "ClipEdit: 設定を既定値で起動しました", &warning);
    }
    if hotkey::register(main, HOTKEY_ID, hotkey).is_err() {
        tray::notify(
            main,
            "ClipEdit",
            &format!(
                "ホットキー {hotkey_text} を登録できませんでした。トレイアイコンから開けます。"
            ),
        );
    }

    let mut msg = MSG::default();
    while unsafe { GetMessageW(&mut msg, None, 0, 0) }.as_bool() {
        if editor.handle_key(&msg) {
            continue;
        }
        unsafe {
            let _ = TranslateMessage(&msg);
            DispatchMessageW(&msg);
        }
    }
    unsafe {
        let _ = CloseHandle(mutex);
    }
}

/// 2つ目の起動なら None。
fn single_instance() -> Option<HANDLE> {
    unsafe {
        let mutex = CreateMutexW(None, true, w!("Local\\ClipEdit-SingleInstance")).ok()?;
        if GetLastError() == ERROR_ALREADY_EXISTS {
            let _ = CloseHandle(mutex);
            return None;
        }
        Some(mutex)
    }
}

fn open_editor() {
    if let Some(editor) = EDITOR.with(|e| e.get()) {
        editor.open(clipboard::read_text);
    }
}

fn toggle_autostart(hwnd: HWND) {
    if let Err(e) = autostart::set(!autostart::is_enabled()) {
        tray::notify(hwnd, "ClipEdit: 自動起動を切り替えられませんでした", &e);
    }
}

extern "system" fn main_proc(hwnd: HWND, msg: u32, wparam: WPARAM, lparam: LPARAM) -> LRESULT {
    match msg {
        WM_HOTKEY => {
            open_editor();
            LRESULT(0)
        }
        tray::WM_TRAY => {
            match (lparam.0 & 0xFFFF) as u32 {
                WM_LBUTTONUP => open_editor(),
                WM_RBUTTONUP => tray::show_menu(hwnd, autostart::is_enabled()),
                _ => {}
            }
            LRESULT(0)
        }
        WM_COMMAND => {
            match wparam.0 & 0xFFFF {
                tray::CMD_OPEN => open_editor(),
                tray::CMD_AUTOSTART => toggle_autostart(hwnd),
                tray::CMD_EXIT => unsafe {
                    let _ = DestroyWindow(hwnd);
                },
                _ => {}
            }
            LRESULT(0)
        }
        WM_DESTROY => {
            hotkey::unregister(hwnd, HOTKEY_ID);
            tray::remove(hwnd);
            unsafe { PostQuitMessage(0) };
            LRESULT(0)
        }
        _ if msg == TASKBAR_CREATED.with(|t| t.get()) && msg != 0 => {
            // エクスプローラーが再起動したらトレイアイコンを付け直す
            let _ = tray::add(hwnd, TRAY_TIP.with(|t| t.get()));
            LRESULT(0)
        }
        _ => unsafe { DefWindowProcW(hwnd, msg, wparam, lparam) },
    }
}
```
